# Extended Industrialization

<MarginFloatingImage src="assets/logo.png" left="0" right="10" />

Extended Industrialization - дополнение для Modern Industrialization, добавляющее множество механизмов и инструментов!

Главная цель Extended Industrialization - расширить содержимое Modern Industrialization, сохранив при этом его
принципы устройства и назначение. Например, [многоблочные механизмы с пакетной обработкой](machines/batching_multiblocks.md)
позволяют ещё сильнее наращивать производительность фабрик, при этом требуя настройки меньшего числа механизмов и
снижая нагрузку на систему.
