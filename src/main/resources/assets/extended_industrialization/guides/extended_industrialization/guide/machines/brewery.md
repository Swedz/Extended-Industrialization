# Brewery

<Row>
	<RecipeFor id="extended_industrialization:steel_brewery" />
	<RecipeFor id="extended_industrialization:electric_brewery" />
</Row>

The brewery functions as a normal machine, but it performs brewing stand recipes. There are a couple differences,
however.

The brewery takes Blazing Essence rather than blaze powder. Each time the brewery brews a set of potions, it consumes
exactly 1mb of Blazing Essence.

The brewery brews _exactly 4_ potions at a time, rather than the brewing stand that allows 1 to 3.
